# Ticket Scraper (standalone dashboard)

Streamlit dashboard over the ticket-scraper semantic layer: collections
home, shared analytics, and one generated page per canonical event.
Reads the bundled published Parquet exports in `data_warehouse/`; no
secrets needed. Generated by `dashboard/export_standalone.sh` in the
ticket-scraper repo — do not edit by hand; re-export to refresh.

Deploy: Streamlit Community Cloud -> main file `streamlit_app.py`.
